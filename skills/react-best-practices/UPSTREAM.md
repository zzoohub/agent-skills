# Upstream and fork posture

A frozen, host-agnostic fork of [`vercel-labs/agent-skills` → `react-best-practices`](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices) (MIT), forked 2026-06-04 (commit `f85be53` in this repo); host-specific notes (Fluid Compute, `@vercel/analytics`, vercel.com citations) were genericized at the fork.

**Policy:** never re-clone over this directory; it would erase the fixes below. Review upstream changes and port single rules by hand into the current file map, dropping anything that depends on Vercel infrastructure. Re-verify every version, API and platform claim against primary sources (react.dev, the Next.js and TanStack docs, MDN, web.dev), then run SKILL.md's Self-Review against the examples.
